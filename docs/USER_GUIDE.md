# 操作指南

## 建立專案

新增專案後設定期間、幣別、金額稅別、每 MD 工時、成本預算、核定收入、預計完成成本（EAC，全期人工與其他成本的總估算）。已投入其他成本可在「編輯專案與預算」中逐筆新增項目、日期、金額與說明；明細合計會納入全期已投入成本。預估餘額自動以全期核定收入減去 EAC 計算；填入的收入與 EAC 應使用相同金額口徑。缺少資料請留空；零表示已確認為零。狀態由管理者判斷，可填寫理由。

剩餘成本 ETC 自動以 EAC 減去全期 AC 計算。AC 是實際工時按成本單價換算的人工成本，加上已投入其他成本；缺少工時成本映射時 AC 與 ETC 留待估。日期篩選只改變工時與選定期間人工成本，這些全期財務值維持相同數值。

成本預算未設定範圍時視為整個專案；填入預算起迄日時不提供全期預算比較，避免混用期間。

## 工時與單價

「本機設定」可保存角色的預設人天售價，新增專案時複製至該專案，之後可獨立調整。公開版本預設空白；本機售價設定包含於資料庫備份。

在「工時與成本 → 成員、角色與單價」同頁維護專案成員、工時角色及各角色的成本／售價單價。可在角色下直接新增、編輯單價，或匯出完整單價 Excel；單價可指定人員及有效期間。角色可以先建檔，稍後補上單價；既有工時或單價中的姓名與角色會顯示為待建檔項目，可逐一確認並加入。新增工時時選擇成員會帶入其預設角色，也能輸入尚未建檔的人員。變更成員的預設角色只影響新工時；編輯工時角色只修改該筆紀錄，不會改寫同姓名的歷史工時。若確實需要批次修正，於成員旁點「更正既有工時」，確認影響筆數後一次套用；歷史人工成本可能跟著變動。已建檔的姓名與角色名稱不可直接更名，請新增正確項目並停用舊項目。售價單獨設定，不用來代替內部成本。同一角色／人員／用途不接受重疊期間；特定人員單價優先於角色通用單價。請確認稅別與專案一致。

成員可選填英文名／別名；同一專案中不可與其他成員的姓名或別名重複。專案、待辦與里程碑、交付與查核、事項追蹤的負責人先選角色再選啟用成員。指派會連結成員，日後變更其預設角色不會改變既有負責人；停用成員保留既有指派，但不能新指派。建立新專案時先新增成員，再指定專案負責人。舊版自由文字負責人會標示「待重新指派」，選定成員並儲存後才取代原值；姓名或別名相符時僅提示可能人選，仍須人工確認。

工時頁可按日期篩選投入趨勢。工時紀錄表可依日期、人員、角色、分類、小時範圍及工作內容篩選，點欄名排序，並以每頁 20、50 或 100 筆瀏覽；Excel 匯出仍包含完整選定專案資料。月份包含年份。工時內容不會自動猜測人員角色。

舊版收入情境紀錄保留於本機資料與備份，介面不再提供新增或編輯。

## 事項追蹤

可依關鍵字、狀態、類型、優先級、負責人與期限區間篩選事項；關鍵字搜尋標題、負責人及內容。點表格欄名可切換升冪與降冪，預設按期限由近到遠排列，未填期限的事項排在最後。「清除篩選」會還原全部事項。

## 匯入來源

1. 選專案、檔案、資料類型與工作表；接受 `.xlsx`、UTF-8 CSV（最多 8 MB／20,000 列）。
2. 自動辨識後調整欄位映射。來源第一列應為欄名；未命名欄與帳密相關欄不能映射。合併欄名或多層標題需先在來源副本整理為單列欄名。
3. 查看預覽與錯誤。公式需有 Excel 已儲存的計算結果；系統不執行巨集或公式。日期接受西元與民國格式。
4. 同內容紀錄保留為重複候選，由使用者確認是否保留。相同來源批次重匯會略過；工時相同來源識別也會略過。修正已匯入工時時，請編輯該筆紀錄，或刪除該筆後匯入更新來源。
5. 交付項目以識別碼＋系統對應更新。來源標記更新不覆蓋已設定的人工檢視、正式結果、適用性與證據。

`OK` 預設表示初步檢視完成；`N/A` 表示目前不需正式查核；`?` 表示疑問。皆不代表正式通過。可調整標記映射或匯入後逐筆編輯。

敏感欄與未命名欄排除不等於完整秘密偵測；上傳前仍應使用不含憑證的整理副本。自動辨識只涵蓋常見欄名，不會猜測自由格式的合約成本工作表，該類資訊可使用專案、單價與款項表單輸入。

## 簡報與備份

報告中心選標題、版本、章節與工時期間，再建立固定快照。新報告會出現在「已封存報告」頂端，可直接下載 PPTX；該區也可重新下載舊報告。工時篩選只套用投入章節；其他章節是建立快照時的最新狀態。報告保留在本機，後續編輯資料不改變舊快照。PowerPoint 表格與圖表可編輯，長清單分頁。

點「備份本機資料」會產生通過 SQLite 完整性檢查的備份並下載。備份含完整業務資料、歷史與報告，請存放於適當的私人目錄。

還原前停止本機服務，再執行：

```powershell
.venv\Scripts\python.exe scripts/restore.py "備份的完整路徑.sqlite3" --server-stopped
```

原資料庫會保留在 `data/backups/`。還原另一資料目錄時加上 `--data-dir`。`--server-stopped` 是操作前提的明確確認，請勿在服務運作時使用。
