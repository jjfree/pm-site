PowerPoint 檢查涵蓋可編輯圖表、表格、完整清單分頁與版面邊界。尚未在不同 PowerPoint 版本逐一人工開啟比對字型替代情形。特定來源的多層／合併欄名可能需要整理副本或人工映射。

## EAC 與 ETC 更新

30 項回歸測試通過。新增涵蓋直接輸入 EAC、全期收入減 EAC、零與未知值、負餘額、ETC＝EAC－全期 AC、篩選外缺漏單價、跨年度篩選、schema 1 遷移前備份、歷史快照保留與遷移失敗回滾。實際成本變動只更新 AC／ETC，不自動改動填入的 EAC。

## 重複啟動更新

Windows 本機 38 項回歸測試通過。啟動器辨識同一工作空間與資料目錄的服務，重複啟動時沿用現有頁面；不同工作空間與未知服務仍回報連接埠衝突，不停止服務。辨識資訊只提供雜湊值，不公開本機路徑。新增測試使用合成 HTTP 服務驗證可用連接埠、服務辨識與 Windows 啟動腳本；Windows 專屬的兩項測試在 Linux CI 跳過。
