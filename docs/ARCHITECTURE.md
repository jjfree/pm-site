# 架構與計算口徑

瀏覽器 → React／TypeScript 本機靜態資產 → FastAPI API → SQLite。

SQLite 保存具有型別驗證的紀錄、版本、編輯稽核、匯入批次、欄位映射與報告快照。金額使用 Decimal，未知與零分開。單人負載採短交易；資料層具備日後替換與遷移的接口，現行 schema 版本為 1。

## 資料模型

專案關聯工時、成本／售價單價、議題／風險／變更／決策、待辦／里程碑、交付查核、收入情境與款項。工時按日保存，不依年度拆成不同專案。單價保存用途、角色、人員、單位、有效期間與稅別。

## 計算

| 指標 | 定義與前提 |
| --- | --- |
| 工時 | 選定專案／日期內的實際時數總和 |
| MD | 工時 ÷ 專案設定的每日標準工時；標準不明則待估 |
| 人工成本 | 每筆工時 × 有效小時單價，或工時 ÷ 每日工時 × 有效人天單價 |
| 已投入成本 | 全期人工成本＋專案已投入其他成本；任何未映射或稅別不一致筆數存在則待估 |
| EAC | 全期已投入成本＋ETC；ETC 留空不當成零 |
| 預估餘額 | 核定收入－EAC；收入、成本與稅別須完整 |
| 修訂收入 | 核定收入－移除的原交付價值＋新增／替代收入 |
| 淨減收 | 移除原價－替代收入；未知替代收入時待估 |
| 修訂成本 | EAC＋情境成本增減；情境不改原核定資料 |

日期篩選下只提供工時與已映射人工成本，不用它與全期完工預估混算。幣別按專案保存，總覽不加總不同專案金額。開票與收款獨立於核定收入。

## 匯入與輸出

來源檔只在短期記憶體中解析，限定格式、大小與展開量。匯入前以欄位白名單映射，排除敏感／未命名欄、驗證每列、預覽，再於交易中寫入。工時識別包含內容雜湊與同內容出現序號，保留合法同內容紀錄。

報告建立時保存固定 JSON 快照。對外版重新依欄位白名單建構，不只在畫面隱藏敏感欄。PPTX 使用原生圖表與表格；CSV／Excel 匯出將可觸發公式的文字轉成文字值。

## 執行邊界

只接受 loopback Host，驗證本機 session、CSRF 與請求來源，不啟用跨域分享。CSP 限制本機資產，不包含分析追蹤或外部字型。服務不會讀取其他專案的設定或憑證。已存在的備份可透過停止服務後的 CLI 還原。
