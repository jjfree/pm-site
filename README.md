# PM Site

單人使用的本機專案管理工作空間。集中查看專案狀態、工時與成本、議題與決策，沿用既有 Excel／CSV，匯出可編輯 PowerPoint。所有範例均為合成資料。

## 快速啟動（Windows）

需要 Python 3.11 或更新版本。下載／clone 後，在專案根目錄執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
scripts\start.bat
```

瀏覽器開啟 `http://127.0.0.1:8765`。初次安裝需要下載套件；安裝後日常操作與匯出不需要網路。已附前端建置檔，日常使用不需要 Node.js。關閉終端機或 Ctrl+C 即可停止。重新執行 `start.bat` 會重啟同一工作空間與資料目錄的服務，載入更新後的程式。

如果 Python 不在 PATH，可透過 `scripts/setup.ps1 -PythonCommand "完整的 python.exe 路徑"` 指定。其他程式或不同工作空間占用 Port 時，使用 `scripts/start.ps1 -Port 8766`；程式不會停止其他服務。

## 主要功能

- 多專案總覽：人工判斷的狀態與理由、工時、未結事項、逾期待辦、下個里程碑。
- 工時與成本：專案成員與工時角色維護、跨年度紀錄、日期篩選、按角色／人員與有效期間套用成本單價、人天換算、收入與完工估算。
- 事項管理：議題、風險、变更、決策；負責人、期限、處置與外部追蹤連結。
- 簡易排程與交付查核：待辦、里程碑、初步檢視、適用性、正式結果與證據分開紀錄。
- 匯入：工作表選擇、欄位映射、敏感欄排除、錯誤與重複候選預覽、映射儲存、批次追蹤。
- 報告：內部／對外欄位範圍、章節選擇、固定資料快照、原生 PowerPoint 圖表與表格、Excel／CSV／圖表 PNG。
- 本機一致性備份、版本衝突檢查與編輯歷史。

## 資料與公開程式碼

SQLite 預設位於 `data/projects.sqlite3`；可用 `PM_DATA_DIR` 指定其他資料夾。資料、備份、輸出、上傳來源與私人設定均不屬於公開程式碼。不要把真實業務資料放在原始碼、測試或公開文檔中。

服務只綁定 loopback，採用本機 session、CSRF 與來源檢查。前端套件與字型不需要 CDN。資料庫沒有應用層加密；裝置帳號／檔案權限與磁碟加密由使用環境管理。此版本適用單人本機操作。

「對外版」排除成本與人員欄位，但專案名稱、摘要、事項標題仍由使用者填寫，分享前應查看快照。它不等於自動匿名化。

見 [操作指南](docs/USER_GUIDE.md)、[架構與計算口徑](docs/ARCHITECTURE.md)、[開發與發布](docs/DEVELOPMENT.md)。

## 範圍

第一版支援檔案匯入與外部議題連結。Redmine API 同步、多使用者、伺服器部署、複雜甘特與工作流程尚未加入。試算不會自動修改核定收入或預算。
